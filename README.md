# نظام جمع ترندات الجزائر ونشرها تلقائياً 🇩🇿

workflow متكامل بلغة Python يجمع أبرز الترندات في الجزائر (يوتيوب + Google Trends) ثم ينشرها تلقائياً على منصاتك: **تيليغرام، فيسبوك، إنستغرام، تيك توك**.

## ما الذي يفعله؟

1. **يجمع** أكثر الفيديوهات رواجاً في الجزائر من YouTube، وأبرز عمليات البحث من Google Trends.
2. **يستبعد** ما سبق نشره حتى لا يتكرر المحتوى.
3. **يصيغ** منشوراً عربياً جاهزاً (نص + هاشتاغات + روابط + صورة مصغّرة).
4. **ينشر** تلقائياً على كل منصة مفعّلة.

## البنية

```
algeria-trends-workflow/
├── main.py                  # المنسّق الرئيسي (شغّل هذا)
├── config.example.json      # نموذج الإعدادات (انسخه إلى config.json)
├── requirements.txt         # المكتبات المطلوبة
├── SETUP_GUIDE.md           # 👈 دليل الإعداد خطوة بخطوة (ابدأ من هنا)
├── run.sh                   # مشغّل مختصر
├── core/                    # النماذج + الإعدادات + منع التكرار
├── collectors/              # جامعات الترندات (youtube, google_trends)
├── content/                 # مولّد المحتوى والتنسيق
├── publishers/              # النشر (telegram, facebook, instagram, tiktok)
└── .github/workflows/       # جدولة تلقائية مجانية عبر GitHub Actions
```

## البدء السريع

```bash
# 1) ثبّت المتطلبات
pip install -r requirements.txt

# 2) انسخ الإعدادات واملأها
cp config.example.json config.json
#   ثم افتح config.json وضع مفاتيحك (راجع SETUP_GUIDE.md)

# 3) جرّب أولاً بدون نشر فعلي
python main.py --dry-run

# 4) عند الاطمئنان، اجعل "dry_run": false في config.json ثم:
python main.py
```

## أهم النقاط قبل أن تبدأ

- **تيليغرام** هو الأسهل ويعمل فوراً بتوكن مجاني — ابدأ به.
- **فيسبوك** يتطلب *صفحة* (لا يمكن النشر على حساب شخصي) + توكن.
- **إنستغرام** يتطلب حساب أعمال/منشئ + أن تكون الصورة على رابط عام.
- **تيك توك** يتطلب فيديو حقيقياً + موافقة على تطبيق المطوّر (الأصعب).
- للتشغيل التلقائي 24/7 راجع قسم الجدولة في `SETUP_GUIDE.md`.
